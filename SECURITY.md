# Security

Do not report live secrets in public issues. For a vulnerability, use GitHub's private vulnerability reporting if enabled; otherwise email contato@brunnodev.store with a minimal sanitized reproducer. Do not include credentials or full private logs.

Reports and job summaries may contain sensitive source text despite best-effort redaction. Read docs/LIMITATIONS.md before sharing them. CIFuse never executes log content. Supported version: latest 0.2.x release. Use a reviewed full commit SHA when consuming the Action. Explicit CLI validation executes trusted project code; it is not a security sandbox.
